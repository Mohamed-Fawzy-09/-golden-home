# Golden Home Website
موقع عربي مستقل لشركة Golden Home لأبواب وشبابيك UPVC.

## الملفات
- `index.html`: الصفحة الرئيسية.
- `style.css`: التصميم المتجاوب.
- `script.js`: حاسبة السعر التقريبية.
- `assets/golden-home-logo.png`: الشعار المرسل.

## النشر المجاني على GitHub Pages
1. أنشئ مستودعًا جديدًا باسم `golden-home` في حساب GitHub.
2. ارفع جميع الملفات والمجلدات الموجودة هنا إلى جذر المستودع.
3. من Settings ثم Pages اختر Deploy from a branch.
4. اختر `main` و`/(root)` ثم Save.
5. سيكون الرابط غالبًا: `https://USERNAME.github.io/golden-home/`.
