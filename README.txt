Golden Home - ملفات الموقع المحدّثة

طريقة التحديث:
1) فك ضغط الملف.
2) ارفع جميع الملفات الموجودة داخله إلى جذر مستودع GitHub Pages.
3) اختر استبدال الملفات القديمة.
4) احتفظ بملف golden-home-logo.png الموجود لديك في المستودع؛ هذا الملف غير مرفق داخل الحزمة.
5) انتظر تحديث GitHub Pages ثم افتح الموقع وحدّث الصفحة تحديثًا كاملًا.
